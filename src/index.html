About Me

A little bit about
who I am.

Hi, I’m António, an 18-year-old frontend developer and web designer based in Lisbon. I first started exploring HTML and CSS when I was 12 and, after some time away, I returned to web development and began studying it more seriously.

I currently work mainly with HTML, CSS and JavaScript and continue developing my skills through personal projects. I particularly enjoy thinking about a website’s structure, its design and how everything adapts across different devices.

This portfolio is also part of that journey. It is a place where I share the projects I build, the technologies I use and what I continue to learn along the way.

How I work
01
Understand

I start by understanding what needs to be built, who it is for, and what the website actually needs to achieve.

02
Plan

I organise the content, layout and functionality before writing the code.

03
Design

I work on typography, spacing, hierarchy and the overall visual direction of the website.

04
Build

I turn the design into responsive HTML, CSS and JavaScript and test it across different screen sizes and environments.

05
Launch

Before publishing, I test the website, fix issues and make final adjustments to improve the overall result.
